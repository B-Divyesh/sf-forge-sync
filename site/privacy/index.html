Privacy

The website

The website does not have analytics or advertising scripts. The sample page stores one browser-only marker under the demo:forge-sync: prefix. Reset demo removes it.

The configuration builder

The configuration builder makes text in your browser. It has no field for a token and does not send the form anywhere.

The CLI

The CLI uses the API endpoints and token environment-variable names in your configuration. Its sample command creates a new temporary directory and does not read your configuration.

Your mirror data

A real run writes its state and archive to locations you choose. The website does not receive repository data or access tokens.

Contact

Send privacy questions to privacy@sociobot.in.
