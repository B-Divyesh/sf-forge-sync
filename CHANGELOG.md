# Changelog

All notable changes follow Keep a Changelog. This project uses semantic versioning.

## [0.1.0] - 2026-08-27

### Added

- Continuous GitHub organization discovery and Git ref mirroring.
- Forgejo, Codeberg, and GitLab target adapters.
- Idempotent issue, label, milestone, comment, and pull-request discussion sync.
- SQLite audit/mapping state and git-tracked portable JSON archive.
- Doctor, status, JSON output, dry-run, and daemon modes.
- Static documentation site and optional Migration Kit license flow.
